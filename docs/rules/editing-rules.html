編集の鉄則とボーカル運用

鉄則

割り当て・人数・音量の変更は arrangement.json のみで行う。 build_mix.py / build_video.py は人数・構成に非依存な汎用エンジンとして保つ（触らない）。
  • start/end は秒。これは解析推定ベースの暫定値。正確な Aメロ/Bメロ/サビ の切れ目は試聴で確定する（機械判定は歌唱/無音の区間までしか分からない）。
  • 全ボーカルトラックは同一楽曲（Suno "controlla"）由来で完全同期・同尺（約292.75秒 / 44.1kHz / 16bit）。タイムアライメント処理は不要。同期していない素材を足すとこの前提が崩れる。
  • 同旋律を複数重ねると「ハモリ」ではなく「ユニゾン（厚み）」になる。本物のハモリは別途ピッチ加工が必要。

ボーカルを増やす手順（最大5人想定）

  1. 音源を stems/vocals/NN_name.wav（連番）に置く。44.1kHz/16bit、同じ楽曲で同尺。
  2. arrangement.json の vocalists に1行追加： 
    "key": { "file": "stems/vocals/NN_name.wav", "gain_db": 0, "pan": 0.0, "display": "表示名" }
  3. 歌わせたい sections の vocals 配列にその key を入れる。
  4. python3 scripts/build_mix.py → python3 scripts/build_video.py で再書き出し。

vocalists: original=ミク（中央） / instant=レン（左 -0.35） / second=リン（右 +0.35）
