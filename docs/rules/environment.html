ffmpeg が drawtext 非対応（重要）

このマシンの ffmpeg（Homebrew 8.0.1）は libfreetype 無しでビルドされており、 drawtext フィルタが使えない（No such filter: 'drawtext'）。 そのため build_video.py はテロップを Pillow で画像化し、 concat demuxer で動画化している。drawtext 方式には戻さないこと。

concat の末尾フレーム伸び対策

concat demuxer は最後の画像の duration を無視するため、放置すると映像が音源より数秒長くなる。 ffmpeg 出力に -t {音源長} を付けて映像尺を音源に揃えている。

フォント

テロップは /System/Library/Fonts/ヒラギノ角ゴシック W6.ttc を使用。 日本語ネイティブのゴシック体でカタカナ・漢字とも字形が自然。

フォントパスに日本語・空白が含まれる。build_video.py は Pillow の ImageFont.truetype() に直接パスを渡すため問題ないが、ffmpeg 側に フォントパスを渡す方式へ変える場合は空白なしの一時パスへコピーすること。
